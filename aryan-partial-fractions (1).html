Integration by Partial Fractions

Chapter: Integration → Topic: Partial Fractions

01 Definition

Partial fractions is a method to integrate a rational function — a ratio of two polynomials P(x) / Q(x) — by breaking it into a sum of simpler fractions that are each easy to integrate.

P(x)Q(x) = A(x − a) + B(x − b) + …

02 Explanation

A big fraction is hard to integrate directly, but a sum of small fractions like A/(x−a) is easy — each one integrates to a logarithm.

It works only when the numerator's degree is less than the denominator's. If not, do polynomial division first. Then:

Three cases by denominator factors: distinct linear factors · repeated linear factors · irreducible quadratic factors — each has its own partial-fraction shape.

03 Diagram

04 Short Summary

  1. Check numerator degree < denominator degree (else divide first).
  2. Factor the denominator fully.
  3. Write it as a sum of fractions with unknown constants A, B, …
  4. Solve for the constants (substitute smart values of x).
  5. Integrate each simple fraction — usually logarithms.

05 Example

Solve: ∫ 1(x−1)(x+2) dx

1(x−1)(x+2) = Ax−1 + Bx+2

So 1 = A(x+2) + B(x−1). Substitute smart values:

x = 1 → 1 = 3A → A = 1/3
x = −2 → 1 = −3B → B = −1/3
∫ = (1/3) ln|x−1| − (1/3) ln|x+2| + C
= (1/3) ln | x−1x+2 | + C

06 Real-World Question

In population growth and chemical reactions, the logistic model needs this integral:

∫ 1x(1−x) dx

Using partial fractions (split into 1/x + 1/(1−x)), can you show that:

= ln | x1−x | + C

This one integral is the backbone of how populations, epidemics and reactions are modelled.

Takeaway

Can't integrate a messy fraction? Break it apart. Factor the bottom, split into simple pieces, and integrate each one — hard becomes easy.
